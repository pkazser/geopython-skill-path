# GeoPython Skill Path

## Python για Γεωπληροφορικούς

Μάθε Python μέσα από πραγματικά προβλήματα GIS και γεωχωρικών δεδομένων.

Το GeoPython Skill Path είναι ένα πρακτικό μονοπάτι μάθησης για φοιτητές και επαγγελματίες της Γεωπληροφορικής.

Δεν χρειάζεται προηγούμενη εμπειρία στον προγραμματισμό.

## Η φιλοσοφία μας

**Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω**
