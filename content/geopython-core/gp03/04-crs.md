# 4. CRS

## Τι θα μάθεις

Το CRS περιγράφει πώς ερμηνεύονται οι συντεταγμένες.

```python
gdf.crs
```

Για longitude/latitude σε μοίρες χρησιμοποιούμε `EPSG:4326`.

## Ορισμός και μετατροπή

```python
gdf = gdf.set_crs("EPSG:4326")
```

Το `set_crs()` δηλώνει τι CRS έχουν ήδη οι τιμές. Δεν μετακινεί τα σημεία. Το `to_crs()` μετατρέπει τις συντεταγμένες σε άλλο σύστημα.

## QA

```python
assert gdf.crs is not None
assert gdf.crs.to_string() == "EPSG:4326"
```

## GeoTip

Δεν χρησιμοποιούμε `to_crs()` για να διορθώσουμε άγνωστο CRS. Πρώτα πρέπει να γνωρίζουμε το αρχικό CRS.
