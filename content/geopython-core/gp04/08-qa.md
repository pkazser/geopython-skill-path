# 8. GeoPython QA

## Τι θα μάθεις

Θα εφαρμόσεις ολοκληρωμένο QA σε layer που διαβάστηκε από GeoPackage.

```python
assert len(parks) > 0
assert parks.crs is not None
assert parks.isna().sum().sum() == 0
assert parks.geometry.notna().all()
assert parks.geometry.is_empty.sum() == 0
assert parks.geometry.is_valid.all()
assert parks.geometry.geom_type.eq("Polygon").all()
assert parks.total_bounds.shape == (4,)
```

Για κάθε layer επιλέγουμε τους ελέγχους που ταιριάζουν στον τύπο του. Στα `water_points` περιμένουμε Points, όχι Polygons.

## Λογικός έλεγχος

Ο αριθμός των features, οι τιμές των attributes, το CRS, τα bounds και η εικόνα στον χάρτη πρέπει να συμφωνούν με το dataset που περιμένουμε.
