# 3. EPSG codes

## Τι θα μάθεις

Θα χρησιμοποιείς EPSG codes ως σύντομη, σαφή αναφορά CRS.

## Γιατί είναι χρήσιμο

Ένα κοινό EPSG code κάνει τον κώδικα αναπαραγώγιμο. Ο αναγνώστης ξέρει ακριβώς ποιο CRS χρησιμοποιήθηκε.

## Παράδειγμα

```python
print(gdf.crs)
print(gdf.crs.to_epsg())
projected = gdf.to_crs(epsg=2100)
```

Το `4326` είναι το WGS 84 που χρησιμοποιούμε για longitude/latitude. Το `2100` είναι το Greek Grid, χρήσιμο για ελληνικά δεδομένα και μονάδες μέτρων.

## Πρακτική στο dataset

Δες το `to_epsg()` πριν και μετά τον μετασχηματισμό. Αν επιστρέψει `None`, δεν σημαίνει απαραίτητα ότι δεν υπάρχει CRS· μπορεί να είναι σύνθετο ή custom. Τότε διάβασε το πλήρες `gdf.crs`.

## QA / λάθη

Έλεγξε `assert gdf.crs.to_epsg() == 4326` και `assert projected.crs.to_epsg() == 2100`. Μην υποθέτεις ότι κάθε ελληνικό dataset έχει 2100· το CRS πρέπει να προκύπτει από τα metadata ή από τεκμηριωμένη απόφαση.
