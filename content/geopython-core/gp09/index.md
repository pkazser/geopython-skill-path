# GP09 — Spatial Join

Στο GP09 συνδέεις σημεία υπηρεσιών με τις διοικητικές περιοχές όπου βρίσκονται. Η ροή είναι **Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω**.

## Τι θα μάθεις

Θα ξεχωρίζεις attribute join από spatial join, θα επιλέγεις left/right dataset και predicate, θα χρησιμοποιείς `gpd.sjoin()`, θα διαβάζεις one-to-many matches και θα κάνεις aggregation. Το dataset `data/gp09/` έχει υπηρεσίες και τρεις διοικητικούς τομείς.
