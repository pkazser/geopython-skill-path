# GeoPython Core

Το **GeoPython Core** αποτελεί τον βασικό κύκλο εκμάθησης του GeoPython Skill Path.

Στόχος είναι να αποκτήσεις τις βασικές δεξιότητες που χρειάζονται για να χρησιμοποιείς την Python σε πραγματικές εργασίες Γεωπληροφορικής.

## Τι θα μάθεις

Στον βασικό κύκλο θα μάθεις σταδιακά να:

- χρησιμοποιείς Python για γεωχωρικά δεδομένα,
- διαβάζεις και εξερευνάς GIS datasets,
- καθαρίζεις και ελέγχεις δεδομένα,
- χειρίζεσαι συστήματα αναφοράς συντεταγμένων,
- φιλτράρεις γεωχωρικά δεδομένα,
- υπολογίζεις αποστάσεις, μήκη και εμβαδά,
- χρησιμοποιείς buffer,
- κάνεις spatial join,
- χρησιμοποιείς clip, intersection και overlay.

## Οι ενότητες

- **GP00** — Python από το μηδέν για Γεωπληροφορικούς
- **GP01** — Το πρώτο μου πραγματικό GeoPython Workflow
- **GP02** — Καθαρισμός γεωχωρικών δεδομένων
- **GP03** — Από CSV σε πλήρες GIS Dataset
- **GP04** — Εξερεύνηση GeoPackage
- **GP05** — CRS χωρίς φόβο
- **GP06** — Filtering γεωχωρικών δεδομένων
- **GP07** — Μετρήσεις γεωμετριών
- **GP08** — Buffer Analysis
- **GP09** — Spatial Join
- **GP10** — Clip, Intersection και Overlay

## Από πού ξεκινάω;

Αν δεν έχεις προηγούμενη εμπειρία με Python, ξεκίνα από το **GP00**.
