# 6. Sanity checks

## Τι θα μάθεις

Θα εντοπίζεις μετρήσεις που είναι τεχνικά έγκυρες αλλά λογικά λάθος.

## Checklist

## Τι αποδεικνύουν

Οι θετικές τιμές αποδεικνύουν ότι υπάρχει γεωμετρική έκταση/μήκος, αλλά όχι ότι η τάξη μεγέθους είναι σωστή. Συνδύασε CRS, bounds, rows, geometry type και γνώση της περιοχής.

```python
assert areas_m["area_m2"].gt(0).all()
assert routes_m["length_m"].gt(0).all()
assert 3_000 < distance_m < 10_000
```

Πρόσθεσε ελέγχους rows, CRS, geometry types και `notna()` στα νέα πεδία.

## Γιατί είναι χρήσιμο

Ένα λάθος CRS μπορεί να επιστρέψει αριθμό χωρίς exception. Η τάξη μεγέθους, το bounds και η οπτική εικόνα είναι δεύτερη γραμμή άμυνας.

## Άσκηση

Κάνε προσωρινά μέτρηση σε EPSG:4326 και σύγκρινε. Μην την εξάγεις· χρησιμοποίησέ την μόνο για να καταλάβεις το σφάλμα.
