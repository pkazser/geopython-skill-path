# 3. Εμβαδόν polygons

## Τι θα μάθεις

Θα υπολογίζεις εμβαδόν και θα το παρουσιάζεις σε m² και hectares.

## Παράδειγμα

```python
areas_m["area_m2"] = areas_m.geometry.area
areas_m["area_ha"] = areas_m["area_m2"] / 10_000
```

Ένα hectare είναι 10.000 m². Το polygon πρέπει να είναι valid και το CRS να έχει γραμμικές μονάδες.

## Εφαρμογή

Υπολόγισε τα δύο areas και σύγκρινε ποιο είναι μεγαλύτερο. Οι περιοχές είναι εκπαιδευτικά μικρές, άρα τα αποτελέσματα πρέπει να είναι λίγες δεκάδες hectares, όχι τεράστιες εκτάσεις.

## QA / λάθη

Έλεγξε `area_m2 > 0`, `geometry.is_valid.all()` και geometry type `Polygon`. Αν ένα invalid polygon δώσει περίεργο αποτέλεσμα, διόρθωσέ το με τεκμηριωμένη διαδικασία πριν τη μέτρηση.
