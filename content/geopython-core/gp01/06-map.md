# 6. Map — Πρώτος χάρτης

## Τι θα μάθεις

Ένας χάρτης βοηθά να ελέγξουμε οπτικά αν οι γεωμετρίες βρίσκονται στη σωστή περιοχή.

```python
ax = gdf.plot(figsize=(8, 6), color="lightgray", edgecolor="black")
selected.plot(ax=ax, color="red", markersize=60)
```

Έτσι βλέπουμε όλα τα σημεία με γκρι και τα επιλεγμένα με κόκκινο.

## Τι ελέγχουμε οπτικά;

- Τα σημεία βρίσκονται περίπου στην ίδια περιοχή;
- Υπάρχει σημείο πολύ μακριά από τα υπόλοιπα;
- Εμφανίζονται τα επιλεγμένα σημεία με διαφορετικό χρώμα;

Ο χάρτης δεν αντικαθιστά τους αριθμητικούς ελέγχους. Είναι ένα επιπλέον εργαλείο κατανόησης και QA.

Το `plot()` δημιουργεί γρήγορη απεικόνιση για εξερεύνηση. Δεν είναι ακόμη πλήρης cartographic map με υπόβαθρο, κλίμακα και υπόμνημα.
