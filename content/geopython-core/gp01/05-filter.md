# 5. Filter — Επιλογή εγγραφών

## Τι θα μάθεις

Θα κρατήσεις μόνο τα σημεία που ικανοποιούν μια σαφή συνθήκη.

```python
selected = gdf[
    (gdf["elevation_m"] > 70) &
    (gdf["status"] == "checked")
].copy()
```

Στην pandas χρησιμοποιούμε `&` για το «και» και βάζουμε κάθε συνθήκη σε παρένθεση.

## Έλεγχος αποτελέσματος

```python
print("Αρχικές γραμμές:", len(gdf))
print("Επιλεγμένες γραμμές:", len(selected))
selected[["name", "category", "elevation_m", "status"]]
```

Πάντα συγκρίνουμε το πλήθος πριν και μετά το φίλτρο. Ένα φίλτρο που επιστρέφει μηδέν γραμμές μπορεί να σημαίνει λάθος συνθήκη.
