# 2. Load — Φόρτωση δεδομένων

## Τι θα μάθεις

Θα φορτώσεις ένα CSV με το `pandas` και θα ελέγξεις το path, το πλήθος των γραμμών και τα ονόματα των στηλών.

```python
import pandas as pd

csv_path = "data/gp01/survey_points.csv"
points = pd.read_csv(csv_path)
print("Γραμμές:", len(points))
print("Στήλες:", list(points.columns))
points.head()
```

Το `csv_path` είναι μεταβλητή. Έτσι μπορούμε να αλλάξουμε το αρχείο σε ένα μόνο σημείο.
Η `head()` εμφανίζει τις πρώτες γραμμές και μας βοηθά να ελέγξουμε αν οι επικεφαλίδες και οι τιμές είναι αναμενόμενες.

## Συνηθισμένο λάθος

Αν εμφανιστεί `FileNotFoundError`, συνήθως το path είναι λάθος ή το αρχείο δεν έχει ανέβει στο Colab. Έλεγξε πρώτα το όνομα και την κατάληξη του αρχείου.

Το CSV είναι απλός πίνακας. Δεν είναι ακόμη γεωχωρικό αρχείο, ακόμη κι αν περιέχει `longitude` και `latitude`.
