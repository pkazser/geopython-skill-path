# 2. Μεταβλητές και τύποι δεδομένων

## Τι θα μάθεις

Σε αυτή την ενότητα θα μάθεις:

- τι είναι μια μεταβλητή,
- πώς αποθηκεύουμε πληροφορία στην Python,
- ποιοι είναι οι βασικοί τύποι δεδομένων,
- πώς χρησιμοποιούνται αριθμοί, κείμενο και λογικές τιμές,
- πώς μπορούμε να περιγράψουμε απλές γεωχωρικές πληροφορίες με μεταβλητές,
- πώς ελέγχουμε τον τύπο μιας τιμής.

---

## Τι είναι μια μεταβλητή;

Μια **μεταβλητή** είναι ένας τρόπος να αποθηκεύσουμε μια τιμή ώστε να μπορούμε να τη χρησιμοποιήσουμε αργότερα.

Παράδειγμα:

```python
city = "Serres"
```

Εδώ:

- `city` είναι το όνομα της μεταβλητής,
- `"Serres"` είναι η τιμή που αποθηκεύουμε.

Μπορούμε μετά να γράψουμε:

```python
print(city)
```

και η Python θα εμφανίσει:

```text
Serres
```

---

## Γιατί χρησιμοποιούμε μεταβλητές;

Φαντάσου ότι θέλουμε να αποθηκεύσουμε πληροφορίες για μία τοποθεσία:

```python
city = "Serres"
population = 60000
elevation = 50
```

Αντί να γράφουμε ξανά και ξανά τις ίδιες τιμές, χρησιμοποιούμε τα ονόματα των μεταβλητών.

```python
print(city)
print(population)
print(elevation)
```

Αυτό κάνει τον κώδικα:

- πιο κατανοητό,
- πιο οργανωμένο,
- πιο εύκολο να αλλάξει,
- πιο εύκολο να επαναχρησιμοποιηθεί.

---

## Ονόματα μεταβλητών

Ένα καλό όνομα μεταβλητής πρέπει να περιγράφει τι αποθηκεύει.

Καλές επιλογές:

```python
city = "Serres"
population = 60000
latitude = 41.09
longitude = 23.55
```

Λιγότερο καλές επιλογές:

```python
x = "Serres"
a = 60000
b = 41.09
```

Ο κώδικας μπορεί να λειτουργεί, αλλά είναι πιο δύσκολο να καταλάβουμε τι σημαίνει κάθε τιμή.

> 💡 **GeoTip**
>
> Στα γεωχωρικά workflows χρησιμοποίησε ονόματα που δείχνουν καθαρά τι περιέχει η μεταβλητή:
>
> `latitude`, `longitude`, `crs`, `area_m2`, `distance_m`.

---

## Βασικοί τύποι δεδομένων

Η Python χρησιμοποιεί διαφορετικούς τύπους δεδομένων ανάλογα με την πληροφορία που αποθηκεύουμε.

Οι βασικοί τύποι που θα χρησιμοποιούμε συχνά είναι:

- `str` — κείμενο,
- `int` — ακέραιος αριθμός,
- `float` — δεκαδικός αριθμός,
- `bool` — λογική τιμή.

---

# Κείμενο — `str`

Οι συμβολοσειρές κειμένου ονομάζονται **strings**.

Παράδειγμα:

```python
city = "Serres"
crs = "EPSG:4326"
```

Οι τιμές κειμένου γράφονται μέσα σε εισαγωγικά.

Μπορούμε να χρησιμοποιήσουμε είτε:

```python
city = "Serres"
```

είτε:

```python
city = 'Serres'
```

Για την ώρα θα χρησιμοποιούμε κυρίως διπλά εισαγωγικά.

---

## Ακέραιοι αριθμοί — `int`

Ακέραιος είναι ένας αριθμός χωρίς δεκαδικό μέρος.

Παράδειγμα:

```python
population = 60000
buildings = 125
```

Δεν χρησιμοποιούμε εισαγωγικά.

Αν γράφαμε:

```python
population = "60000"
```

η Python θα το θεωρούσε κείμενο και όχι αριθμό.

Αυτό είναι σημαντικό όταν θέλουμε να κάνουμε υπολογισμούς.

---

## Δεκαδικοί αριθμοί — `float`

Για αριθμούς με δεκαδικό μέρος χρησιμοποιούμε `float`.

Παράδειγμα:

```python
latitude = 41.09
longitude = 23.55
elevation = 52.7
```

Στην Python χρησιμοποιούμε **τελεία** ως δεκαδικό διαχωριστικό.

Σωστό:

```python
area = 1250.5
```

Λάθος:

```text
area = 1250,5
```

> ⚠️ **Πρόσεξε**
>
> Στην ελληνική γραφή συχνά χρησιμοποιούμε κόμμα στους δεκαδικούς αριθμούς.
>
> Στην Python γράφουμε:
>
> `1250.5`
>
> και όχι:
>
> `1250,5`

---

## Λογικές τιμές — `bool`

Μια λογική τιμή μπορεί να είναι μόνο:

```python
True
```

ή:

```python
False
```

Παράδειγμα:

```python
is_capital = False
has_geometry = True
```

Οι λογικές τιμές είναι πολύ χρήσιμες όταν αργότερα αρχίσουμε να κάνουμε ελέγχους και filtering.

---

## Ένα γεωχωρικό αντικείμενο ως μεταβλητές

Ας περιγράψουμε ένα σημείο με απλές μεταβλητές:

```python
name = "Station A"
longitude = 23.55
latitude = 41.09
elevation = 125.4
crs = "EPSG:4326"
active = True
```

Παρατήρησε ότι χρησιμοποιούμε διαφορετικούς τύπους:

```text
name       → str
longitude  → float
latitude   → float
elevation  → float
crs        → str
active     → bool
```

Αυτό είναι ήδη μια μικρή αναπαράσταση ενός γεωχωρικού αντικειμένου.

---

## Εμφάνιση πολλών τιμών

Μπορούμε να χρησιμοποιήσουμε:

```python
print(name)
print(longitude)
print(latitude)
```

ή να εμφανίσουμε περισσότερες πληροφορίες στην ίδια γραμμή:

```python
print("Name:", name)
print("Coordinates:", longitude, latitude)
print("CRS:", crs)
```

Το αποτέλεσμα θα είναι περίπου:

```text
Name: Station A
Coordinates: 23.55 41.09
CRS: EPSG:4326
```

---

## Η συνάρτηση `type()`

Αν δεν ξέρουμε τι τύπο έχει μια μεταβλητή, μπορούμε να χρησιμοποιήσουμε τη συνάρτηση:

```python
type()
```

Παράδειγμα:

```python
city = "Serres"
population = 60000
latitude = 41.09

print(type(city))
print(type(population))
print(type(latitude))
```

Θα πάρουμε περίπου:

```text
<class 'str'>
<class 'int'>
<class 'float'>
```

---

## 🧪 Δοκίμασέ το

Δημιούργησε:

```python
crs = "EPSG:2100"
epsg_code = 2100
```

και μετά:

```python
print(type(crs))
print(type(epsg_code))
```

Τι παρατηρείς;

Παρότι και οι δύο τιμές περιέχουν τον αριθμό `2100`, δεν είναι ο ίδιος τύπος δεδομένων.

Η πρώτη είναι κείμενο.

Η δεύτερη είναι αριθμός.

---

## Απλοί αριθμητικοί υπολογισμοί

Οι αριθμητικές μεταβλητές μπορούν να χρησιμοποιηθούν σε υπολογισμούς.

Παράδειγμα:

```python
width = 100
height = 50

area = width * height

print(area)
```

Αποτέλεσμα:

```text
5000
```

Αν οι διαστάσεις είναι σε μέτρα, τότε το αποτέλεσμα είναι:

```text
5000 m²
```

Αυτό είναι ήδη ένα παράδειγμα που έχει άμεση σχέση με GIS.

---

## Από τετραγωνικά μέτρα σε εκτάρια

Ένα εκτάριο είναι:

```text
10,000 m²
```

Άρα:

```python
area_m2 = 25000
area_ha = area_m2 / 10000

print(area_ha)
```

Αποτέλεσμα:

```text
2.5
```

Δηλαδή:

```text
2.5 hectares
```

Αργότερα θα κάνουμε ακριβώς τέτοιους υπολογισμούς πάνω σε πραγματικές γεωμετρίες.

---

## Πράξεις στην Python

Οι βασικοί αριθμητικοί τελεστές είναι:

| Πράξη | Σύμβολο |
|---|---|
| Πρόσθεση | `+` |
| Αφαίρεση | `-` |
| Πολλαπλασιασμός | `*` |
| Διαίρεση | `/` |
| Ύψωση σε δύναμη | `**` |

Παράδειγμα:

```python
distance1 = 120
distance2 = 80

total_distance = distance1 + distance2

print(total_distance)
```

## Αλλαγή τιμής μεταβλητής

Μια μεταβλητή μπορεί να αλλάξει τιμή.

Παράδειγμα:

```python
distance = 100

print(distance)
```

μετά:

```python
distance = 150

print(distance)
```

Η δεύτερη ανάθεση αντικαθιστά την προηγούμενη τιμή.

---

## Μετατροπή τύπων

Μερικές φορές μια τιμή είναι αποθηκευμένη ως κείμενο ενώ εμείς θέλουμε να τη χρησιμοποιήσουμε ως αριθμό.

Παράδειγμα:

```python
population = "60000"
```

Αυτή είναι συμβολοσειρά.

Μπορούμε να τη μετατρέψουμε:

```python
population = int(population)
```

Τώρα:

```python
print(type(population))
```

θα δείξει:

```text
<class 'int'>
```

Αντίστοιχα μπορούμε να χρησιμοποιήσουμε:

```python
float()
str()
int()
```

---

## ⚠️ Συνηθισμένο λάθος: αριθμός ως κείμενο

Δες το παρακάτω:

```python
distance = "100"

print(distance + distance)
```

Ίσως περιμένουμε:

```text
200
```

αλλά θα πάρουμε:

```text
100100
```

Γιατί;

Επειδή η Python βλέπει το `"100"` ως κείμενο και ενώνει τα δύο strings.

Η σωστή μορφή είναι:

```python
distance = 100

print(distance + distance)
```

και το αποτέλεσμα είναι:

```text
200
```

---

## ⚠️ Συνηθισμένο λάθος: κεφαλαία και πεζά

Η Python ξεχωρίζει κεφαλαία και πεζά.

Αν γράψουμε:

```python
city = "Serres"
```

και μετά:

```python
print(City)
```

θα πάρουμε error.

Για την Python:

```text
city
```

και:

```text
City
```

είναι δύο διαφορετικά ονόματα.

## 🧪 Mini άσκηση

Δημιούργησε μεταβλητές για ένα γεωγραφικό σημείο με τα παρακάτω στοιχεία:

- όνομα: `Survey Point 01`
- X: `445250.50`
- Y: `4548120.75`
- υψόμετρο: `82.4`
- CRS: `EPSG:2100`
- ενεργό: `True`

Στη συνέχεια:

1. εμφάνισε όλες τις τιμές,
2. εμφάνισε τον τύπο κάθε μεταβλητής,
3. πρόσθεσε 1.5 μέτρο στο υψόμετρο,
4. εμφάνισε το νέο υψόμετρο.

---

## Ενδεικτική λύση

```python
name = "Survey Point 01"
x = 445250.50
y = 4548120.75
elevation = 82.4
crs = "EPSG:2100"
active = True

print(name)
print(x)
print(y)
print(elevation)
print(crs)
print(active)

print(type(name))
print(type(x))
print(type(y))
print(type(elevation))
print(type(crs))
print(type(active))

elevation = elevation + 1.5

print("New elevation:", elevation)
```
