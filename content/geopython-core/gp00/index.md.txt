# GP00 — Python από το μηδέν για Γεωπληροφορικούς

## Τι θα κάνουμε

Σε αυτή την ενότητα θα κάνουμε την πρώτη γνωριμία με την Python μέσα από παραδείγματα που έχουν νόημα για έναν φοιτητή ή επαγγελματία της Γεωπληροφορικής.

Δεν χρειάζεται να έχεις προηγούμενη εμπειρία στον προγραμματισμό.

Στόχος δεν είναι να μάθεις όλη την Python.

Στόχος είναι να αποκτήσεις τις βασικές γνώσεις που χρειάζονται για να αρχίσεις να χρησιμοποιείς την Python σε πραγματικά γεωχωρικά προβλήματα.

## Μαθησιακοί στόχοι

Μετά την ολοκλήρωση της ενότητας θα μπορείς να:

- εξηγείς τι είναι η Python,

- χρησιμοποιείς το Google Colab,
- δημιουργείς μεταβλητές,
- χρησιμοποιείς αριθμούς και κείμενο,

- χρησιμοποιείς απλές συνθήκες `if`,
- χρησιμοποιείς επαναλήψεις `for`,
- δημιουργείς απλές συναρτήσεις,
- εισάγεις βιβλιοθήκες,
- χρησιμοποιείς βασικά το `pandas`,

## Γιατί Python στη Γεωπληροφορική;

Σε ένα GIS μπορούμε να κάνουμε πολλές εργασίες μέσα από γραφικό περιβάλλον.

Όμως συχνά χρειάζεται να:

- επαναλάβουμε την ίδια εργασία σε πολλά αρχεία,
- επεξεργαστούμε χιλιάδες εγγραφές,
- αυτοματοποιήσουμε μια διαδικασία,
- ελέγξουμε δεδομένα,
- συνδυάσουμε διαφορετικές πηγές,
- δημιουργήσουμε μια επαναλήψιμη διαδικασία ανάλυσης.

Εδώ η Python γίνεται ιδιαίτερα χρήσιμη.

> 💡 **GeoTip**
>
> Δεν χρησιμοποιούμε Python επειδή είναι «καλύτερη» από το GIS.
> Τη χρησιμοποιούμε όταν μας βοηθά να κάνουμε μια εργασία πιο γρήγορα, πιο επαναλήψιμα ή πιο αξιόπιστα.

## Notebook και Script

Ένα **Jupyter Notebook** είναι κατάλληλο για:

- μάθηση,
- πειραματισμό,
- ανάλυση βήμα προς βήμα,
- εμφάνιση αποτελεσμάτων μαζί με τον κώδικα.

Ένα **Python script (`.py`)** είναι κατάλληλο για:

- επαναχρησιμοποίηση,
- αυτοματοποίηση,
- επαναλαμβανόμενες εργασίες.

Στο GeoPython Skill Path θα χρησιμοποιήσουμε και τα δύο.
