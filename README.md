# GeoPython Skill Path

Ένα πρακτικό μονοπάτι εκμάθησης Python για φοιτητές και επαγγελματίες της Γεωπληροφορικής.

## Στόχος

Το GeoPython Skill Path δεν είναι ένα κλασικό μάθημα προγραμματισμού.

Στόχος είναι ο εκπαιδευόμενος να μάθει μόνο την Python που χρειάζεται για να λύνει πραγματικά προβλήματα γεωχωρικών δεδομένων.

Η βασική φιλοσοφία είναι:

**Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω**

## Δομή εκμάθησης

### GeoPython Core

- GP00 — Python από το μηδέν για Γεωπληροφορικούς
- GP01 — Το πρώτο μου πραγματικό GeoPython Workflow
- GP02 — Καθαρισμός γεωχωρικών δεδομένων
- GP03 — Από CSV σε πλήρες GIS Dataset
- GP04 — Εξερεύνηση GeoPackage
- GP05 — CRS χωρίς φόβο
- GP06 — Filtering γεωχωρικών δεδομένων
- GP07 — Μετρήσεις γεωμετριών
- GP08 — Buffer Analysis
- GP09 — Spatial Join
- GP10 — Clip, Intersection και Overlay

### Automation Core

- GP11 — Dissolve & GroupBy
- GP12 — Nearest Feature
- GP13 — Batch Processing
- GP14 — Merge Many Files
- GP15 — Automatic GIS QA

## Capstone Project

Μετά την ολοκλήρωση του Core, ο εκπαιδευόμενος εφαρμόζει τις γνώσεις του σε ένα ολοκληρωμένο γεωχωρικό πρόβλημα.
